# AccBot 脚本语法手册

> 脚本运行在云手机的 AccBot 执行器上，语法为 JavaScript（async/await）。
> 所有异步操作必须 `await`，脚本是代码片段，不需要 import/export。

## 全局函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `sleep(ms)` | 休眠 | `await sleep(1000)` |
| `log(msg)` | 输出日志（实时上报服务端） | `await log("执行中...")` |
| `setProgress(msg)` | 更新进度状态（实时上报） | `await setProgress("正在登录")` |
| `getResource(name)` | 获取已推送的资源文件路径 | `getResource("button.png")` |
| `return` | 返回结果给服务端 | `return { success: true, data: {} }` |
| `throw` | 抛出错误 | `throw new Error("失败原因")` |

## 节点查找 (android.acc)

**findViewEx 参数说明：**
- 第一个参数：查找条件对象，多个条件同时传时为 AND 关系（全部满足才匹配）
- 第二个参数：超时毫秒数（必填），在此时间内反复查找直到找到或超时返回 null
- 传 0 表示只查一次不等待

```javascript
// 按条件查找（推荐），多条件为 AND 关系
let node = await android.acc.findViewEx({
    text: "登录",                          // 文本完全匹配
    className: "android.widget.Button",    // 且 类型为 Button
    resourceId: "com.app:id/btn_login",    // 且 资源ID匹配
    isVisibleToUser: true,                 // 且 可见
}, 5000)  // 超时 5 秒，必填

if (node) {
    await node.click()        // 点击节点 bounds 中心坐标
    await node.clickEx()      // 智能点击：向上查找可点击的父节点再点击（适合节点本身不可点击的情况）
    let json = await node.toJson()
}

// 按 ID 查找
let node = await android.acc.findViewById("com.app:id/btn", 5000)

// 批量查找（返回数组，不等待）
let nodes = await android.acc.findViews({ className: "android.widget.TextView" })
```

## OCR 文字识别 (android.ocr)

> 前置条件：设备需开启无障碍服务权限，否则报 `-1001 必要权限没有打开`。
> 首次使用前，通过 Shell 确认权限：`jpy-cloud shell -s <服务器> -k <密钥> <设备ID> "settings get secure enabled_accessibility_services"`

```javascript
// 全屏识别
let results = await android.ocr.ocr()
// 返回: [{ label: "文字", x, y, x2, y2, qua }, ...]

// 区域识别
let results = await android.ocr.ocrArea(80, 100, 200, 500, 400)

// 查找并点击文字
let item = android.ocrUtil.getResByLabel(results, "登录")
await android.ocrUtil.clickResByLabel(results, "登录")
```

## 输入操作 (android.input)

> 注意：inputStr 往当前获得焦点的输入框输入文字。使用前必须先点击目标输入框使其获得焦点。

```javascript
// 标准输入流程：先点击输入框 → 再输入文字
let input = await android.acc.findViewEx({ resourceId: "com.app:id/username" }, 5000)
await input.click()          // 先让输入框获得焦点
await sleep(300)             // 等键盘弹出
await android.input.inputStr("Hello World")   // 往焦点控件输入

await android.input.paste()                    // 粘贴剪贴板内容
await android.input.selectAllText()            // 全选当前输入框
await android.input.setClipboardContent("文本") // 设置剪贴板
```

## 常用技巧

### 弹窗处理

APP 启动后常弹出权限请求、广告、更新提示等弹窗，建议封装通用关闭函数：

```javascript
// 通用弹窗关闭（在关键操作前调用）
async function dismissPopups(maxRetries = 3) {
    const keywords = ['允许', '确定', '同意', '知道了', '跳过', '以后再说', '取消', '关闭', '暂不', 'Allow', 'OK', 'Skip', 'Later']
    for (let i = 0; i < maxRetries; i++) {
        let found = false
        for (let kw of keywords) {
            let btn = await android.acc.findViewEx({ text: kw }, 500)  // 短超时快速扫
            if (btn) {
                await btn.click()
                await sleep(500)
                found = true
                break
            }
        }
        if (!found) break  // 没弹窗了，退出
    }
}

// 使用方式
await android.app.runApp("com.xunmeng.pinduoduo")
await sleep(3000)
await dismissPopups()  // 关掉启动弹窗
// 继续正常操作...
```

### 等待页面加载

```javascript
// 等待某个元素出现，作为页面加载完成的标志
async function waitForPage(text, timeout = 10000) {
    let el = await android.acc.findViewEx({ text }, timeout)
    if (!el) throw new Error(`页面加载超时：未找到 "${text}"`)
    return el
}

await android.app.runApp("com.xunmeng.pinduoduo")
await waitForPage("首页", 10000)  // 等首页加载完
```

## 编写规范

1. 所有异步操作必须 `await`
2. 脚本是代码片段，不需要 `import/export`，不需要函数包裹
3. 用 `log()` 打关键日志，用 `setProgress()` 上报进度
4. 用 `return` 返回结果，用 `throw` 抛出错误
5. 用 `try/catch` 包裹主逻辑做异常处理

## 脚本模板

```javascript
await log("脚本开始")

try {
    await setProgress("启动应用")
    await android.app.runApp("com.example.app")
    await sleep(3000)

    await setProgress("查找目标")
    let el = await android.acc.findViewEx({ text: "目标" }, 10000)
    if (!el) throw new Error("未找到目标元素")

    await setProgress("执行操作")
    await el.click()
    await sleep(1000)

    await log("执行成功")
    return { success: true }
} catch (e) {
    await log(`出错: ${e.message}`)
    throw e
}
```
