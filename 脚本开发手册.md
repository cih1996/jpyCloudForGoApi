# AccBot 脚本执行器 - 开发手册

## 概述

本项目是一个动态脚本执行器，运行在云手机上，通过 WebSocket 与服务器实时通信，接收并执行脚本任务。

---

## 架构设计

### 整体架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                          服务端 (Go/Node)                            │
│  - 管理设备连接                                                       │
│  - 下发脚本任务 (TASK_PUSH / DEBUG_EXEC)                              │
│  - 接收执行结果、日志、截图                                            │
│  - 脚本/资源缓存管理                                                  │
└───────────────────────────────┬─────────────────────────────────────┘
                                │ WebSocket (二进制协议)
                                │ 支持 TCP 连接复用/网关代理
                                ▼
┌─────────────────────────────────────────────────────────────────────┐
│                     脚本执行器 (APK - 本项目)                         │
│                                                                     │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐                 │
│  │ connection  │  │   cache     │  │  executor   │                 │
│  │ WebSocket   │  │ 脚本/资源   │  │  脚本执行    │                 │
│  │ 连接管理     │  │ 本地缓存    │  │  超时控制    │                 │
│  └─────────────┘  └─────────────┘  └─────────────┘                 │
│                                                                     │
│  功能：                                                              │
│  1. 建立 WebSocket 连接，上报设备 ID                                  │
│  2. 接收任务 → 检查缓存 → 执行脚本                                    │
│  3. 实时上报：状态、进度、日志、返回值、截图                           │
│  4. 心跳保活、断线自动重连                                            │
└─────────────────────────────────────────────────────────────────────┘
```

### 通信流程

```
设备                                              服务端
  │                                                  │
  │ ──────── WebSocket 连接 ────────────────────────▶│
  │                                                  │
  │ ──────── INIT (设备ID, 版本) ───────────────────▶│
  │                                                  │
  │ ◀─────── TASK_PUSH (taskId, hash, code?) ────── │
  │                                                  │
  │ [如果 code 为空且本地无缓存]                       │
  │ ──────── SCRIPT_PULL (hash) ───────────────────▶│
  │ ◀─────── SCRIPT_DATA (hash, code) ──────────── │
  │                                                  │
  │ [执行脚本...]                                     │
  │                                                  │
  │ ──────── PROGRESS_REPORT (进度) ───────────────▶│
  │ ──────── LOG_REPORT (日志) ────────────────────▶│
  │ ──────── TASK_RESULT (结果) ───────────────────▶│
  │                                                  │
  │ ◀──────────────── 心跳 ────────────────────────▶│
  │                                                  │
```

### 缓存机制

为优化大脚本传输，执行器支持本地缓存：

```
/sdcard/accbot/cache/
├── scripts/           # 脚本缓存 (按 hash 存储)
│   ├── a1b2c3d4.js
│   └── e5f6g7h8.js
├── resources/         # 资源缓存 (图片等)
│   ├── button.png
│   └── icon.png
└── cache_index.json   # 缓存索引
```

**缓存策略：**
- 脚本：最多 100 个，LRU 淘汰
- 资源：最多 200 个，LRU 淘汰
- 服务端可选择：直接推送代码 或 只推送 hash（设备自动拉取）

## 任务类型

### 1. 普通任务 (TASK_PUSH)

服务端下发任务，支持缓存：

```json
{
  "taskId": "task_001",
  "scriptHash": "a1b2c3d4",
  "code": "await log('hello')",  // 可选，为空则从缓存读取
  "resources": ["button.png"],   // 依赖的资源
  "timeout": 60000,
  "priority": 1
}
```

### 2. 调试任务 (DEBUG_EXEC)

开发调试用，不走缓存，立即执行：

```json
{
  "taskId": "debug_001",
  "code": "await log('调试代码')",
  "timeout": 30000
}
```

### 3. 系统命令 (COMMAND)

```json
{
  "command": "screenshot",    // 截图
  "params": { "quality": 80 }
}

{
  "command": "clearCache",    // 清空缓存
  "params": { "type": "all" } // all / scripts / resources
}
```

## 全局 API

脚本中可直接使用以下全局变量和函数：

| API | 说明 | 示例 |
|-----|------|------|
| `android` | AccBot SDK 主对象 | `android.touch.click(x, y)` |
| `sleep(ms)` | 休眠指定毫秒 | `await sleep(1000)` |
| `log(msg)` | 输出日志（实时上报服务端） | `await log("执行中...")` |
| `setProgress(msg)` | 更新进度状态（实时上报） | `await setProgress("正在登录")` |
| `getResource(name)` | 获取缓存的资源路径 | `getResource("button.png")` |

## Android 操作 API

### 1. 触摸操作 (android.touch)

```javascript
// 点击
await android.touch.click(500, 300)           // 点击坐标 (x, y)
await android.touch.click(500, 300, 100)      // 点击并按住 100ms

// 长按
await android.touch.longClick(500, 300)       // 长按 1 秒
await android.touch.longClick(500, 300, 2000) // 长按 2 秒

// 滑动
await android.touch.swipe(100, 800, 100, 200, 500)  // 从 (100,800) 滑到 (100,200)，耗时 500ms

// 按键
await android.touch.press(keyCode.KEYCODE_BACK)     // 返回键
await android.touch.press(keyCode.KEYCODE_HOME)     // Home 键

// 底层触摸
await android.touch.down(500, 300)    // 按下
await android.touch.move(500, 400)    // 移动
await android.touch.up(500, 400)      // 抬起
```

### 2. 节点查找 (android.acc)

```javascript
// 按条件查找（推荐）
let node = await android.acc.findViewEx({
    text: "登录",
    className: "android.widget.Button",
    resourceId: "com.app:id/btn_login",
    isVisibleToUser: true,
}, 5000)  // 超时 5 秒

if (node) {
    await node.click()           // 点击
    await node.clickEx()         // 智能点击
    let json = await node.toJson()
}

// 按 ID 查找
let node = await android.acc.findViewById("com.app:id/btn", 5000)

// 批量查找
let nodes = await android.acc.findViews({ className: "android.widget.TextView" })
```

### 3. OCR 文字识别 (android.ocr)

```javascript
// 全屏识别
let results = await android.ocr.ocr()
// 返回: [{ label: "文字", x, y, x2, y2, qua }, ...]

// 区域识别
let results = await android.ocr.ocrArea(80, 100, 200, 500, 400)

// 查找并点击文字
let item = android.ocrUtil.getResByLabel(results, "登录")
await android.ocrUtil.clickResByLabel(results, "登录")
```

### 4. 输入操作 (android.input)

```javascript
await android.input.inputStr("Hello World")   // 输入文字
await android.input.paste()                    // 粘贴
await android.input.selectAllText()            // 全选
await android.input.setClipboardContent("文本") // 设置剪贴板
```

### 5. Shell 命令 (android.shell)

```javascript
let result = await android.shell.executeCommand("ls /sdcard")
await android.shell.executeCommandBackground("am start -n com.app/.Main")
```

### 6. 文件操作 (android.file)

```javascript
let content = await android.file.readStr("/sdcard/config.txt")
await android.file.writeStr("/sdcard/config.txt", "内容", false)
await android.file.downloadFile("http://example.com/file.apk", "/sdcard/app.apk")
```

### 7. 应用管理 (android.app)

```javascript
await android.app.runApp("com.tencent.mm")    // 启动微信
await android.app.toast("提示消息", 3000)
let info = await android.app.getDeviceInfo()
```

### 8. 图像找图 (android.openCvUtil)

```javascript
// 查找图片（需先通过 RESOURCE_PUSH 推送图片）
let result = await android.openCvUtil.findImgByName("button.png")
if (result) {
    await android.touch.click(result.x, result.y)
}
```

### 9. 截图 (android.image)

```javascript
let img = await android.image.getImg()
let base64 = await img.getBase64()
let width = await img.getWidth()
```

## AI 编写脚本规范

### 必须遵守的规则

1. **所有异步操作必须 await**
   ```javascript
   // ✅ 正确
   await android.touch.click(500, 300)
   await sleep(1000)

   // ❌ 错误
   android.touch.click(500, 300)
   ```

2. **脚本是代码片段，不需要 import/export**
   ```javascript
   // ✅ 正确
   await log("开始")
   await android.touch.click(500, 300)
   return { success: true }

   // ❌ 错误
   import { android } from 'xxx'
   export default async function() { ... }
   ```

3. **使用 log() 和 setProgress() 上报状态**
   ```javascript
   await log("开始登录流程")
   await setProgress("正在输入密码")
   ```

4. **使用 return 返回结果**
   ```javascript
   return { success: true, data: { userId: 123 } }
   ```

5. **使用 throw 抛出错误**
   ```javascript
   if (!node) {
     throw new Error("未找到目标元素")
   }
   ```

### 脚本模板

```javascript
await log("脚本开始执行")

try {
    // 步骤 1
    await setProgress("启动应用")
    await android.app.runApp("com.example.app")
    await sleep(3000)

    // 步骤 2
    await setProgress("等待页面加载")
    let element = await android.acc.findViewEx({ text: "目标" }, 10000)
    if (!element) {
        throw new Error("页面加载超时")
    }

    // 步骤 3
    await setProgress("执行操作")
    await element.click()
    await sleep(1000)

    await log("执行成功")
    return { success: true }

} catch (e) {
    await log(`出错: ${e.message}`)
    throw e
}
```

## 完整示例

### 示例 1：登录流程

```javascript
await log("开始登录")
await setProgress("启动应用")

await android.app.runApp("com.example.app")
await sleep(3000)

await setProgress("查找登录按钮")
let loginBtn = await android.acc.findViewEx({ text: "登录" }, 10000)
if (!loginBtn) throw new Error("未找到登录按钮")

await setProgress("输入账号")
let username = await android.acc.findViewById("com.example:id/username")
await username.click()
await sleep(500)
await android.input.inputStr("myuser")

await setProgress("输入密码")
let password = await android.acc.findViewById("com.example:id/password")
await password.click()
await sleep(500)
await android.input.inputStr("mypass")

await setProgress("点击登录")
await loginBtn.click()
await sleep(3000)

await log("登录完成")
return { success: true }
```

### 示例 2：刷视频

```javascript
await log("开始刷视频")

for (let i = 0; i < 10; i++) {
    await setProgress(`观看第 ${i + 1} 个视频`)

    let watchTime = 10000 + Math.random() * 10000
    await log(`观看 ${Math.round(watchTime/1000)} 秒`)
    await sleep(watchTime)

    await android.touch.swipe(540, 1500, 540, 500, 300)
    await sleep(1000)
}

await log("刷视频完成")
return { videosWatched: 10 }
```

### 示例 3：OCR 识别

```javascript
await log("开始 OCR")
await setProgress("截图识别中")

let results = await android.ocr.ocr()
await log(`识别到 ${results.length} 个区域`)

let confirmBtn = android.ocrUtil.getResByLabel(results, "确定")
if (confirmBtn) {
    await android.ocrUtil.clickResByLabel(results, "确定")
    await log("点击确定")
}

return { found: !!confirmBtn }
```

## 调试技巧

1. **使用 DEBUG_EXEC** - 开发时用调试模式，不走缓存，方便快速迭代
2. **多用 log()** - 关键步骤打日志，服务端实时可见
3. **善用 setProgress()** - 让服务端知道当前执行到哪一步
4. **合理设置超时** - 服务端下发任务时指定 timeout
5. **异常处理** - 用 try/catch 包裹，throw 抛出错误
