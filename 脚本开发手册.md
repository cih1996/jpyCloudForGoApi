# AccBot 脚本语法手册

> 脚本运行在云手机的 AccBot 执行器上，语法为 JavaScript（async/await）。
> 所有异步操作必须 `await`，脚本是代码片段，不需要 import/export。

## 全局函数

| 函数 | 说明 | 示例 |
|------|------|------|
| `sleep(ms)` | 休眠 | `await sleep(1000)` |
| `log(msg)` | 输出日志（实时上报服务端） | `await log("执行中...")` |
| `setProgress(msg)` | 更新进度状态（实时上报） | `await setProgress("正在登录")` |
| `getResource(name)` | 获取已推送的资源文件路径 | `getResource("button.png")` |
| `return` | 返回结果给服务端 | `return { success: true, data: {} }` |
| `throw` | 抛出错误 | `throw new Error("失败原因")` |

## 触摸操作 (android.touch)

```javascript
await android.touch.click(500, 300)              // 点击坐标
await android.touch.click(500, 300, 100)          // 点击并按住 100ms
await android.touch.longClick(500, 300)           // 长按 1 秒
await android.touch.longClick(500, 300, 2000)     // 长按 2 秒
await android.touch.swipe(100, 800, 100, 200, 500) // 滑动，耗时 500ms
await android.touch.press(keyCode.KEYCODE_BACK)   // 返回键
await android.touch.press(keyCode.KEYCODE_HOME)   // Home 键

// 底层触摸
await android.touch.down(500, 300)
await android.touch.move(500, 400)
await android.touch.up(500, 400)
```

## 节点查找 (android.acc)

```javascript
// 按条件查找（推荐）
let node = await android.acc.findViewEx({
    text: "登录",
    className: "android.widget.Button",
    resourceId: "com.app:id/btn_login",
    isVisibleToUser: true,
}, 5000)  // 超时 5 秒

if (node) {
    await node.click()        // 点击节点
    await node.clickEx()      // 智能点击
    let json = await node.toJson()
}

// 按 ID 查找
let node = await android.acc.findViewById("com.app:id/btn", 5000)

// 批量查找
let nodes = await android.acc.findViews({ className: "android.widget.TextView" })
```

## OCR 文字识别 (android.ocr)

```javascript
// 全屏识别
let results = await android.ocr.ocr()
// 返回: [{ label: "文字", x, y, x2, y2, qua }, ...]

// 区域识别
let results = await android.ocr.ocrArea(80, 100, 200, 500, 400)

// 查找并点击文字
let item = android.ocrUtil.getResByLabel(results, "登录")
await android.ocrUtil.clickResByLabel(results, "登录")
```

## 编写规范

1. 所有异步操作必须 `await`
2. 脚本是代码片段，不需要 `import/export`，不需要函数包裹
3. 用 `log()` 打关键日志，用 `setProgress()` 上报进度
4. 用 `return` 返回结果，用 `throw` 抛出错误
5. 用 `try/catch` 包裹主逻辑做异常处理

## 脚本模板

```javascript
await log("脚本开始")

try {
    await setProgress("启动应用")
    await android.app.runApp("com.example.app")
    await sleep(3000)

    await setProgress("查找目标")
    let el = await android.acc.findViewEx({ text: "目标" }, 10000)
    if (!el) throw new Error("未找到目标元素")

    await setProgress("执行操作")
    await el.click()
    await sleep(1000)

    await log("执行成功")
    return { success: true }
} catch (e) {
    await log(`出错: ${e.message}`)
    throw e
}
```
